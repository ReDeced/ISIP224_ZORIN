# Практика №5 — Система управления университетом

Консольное приложение на C# (.NET 8). Проект построен на четырёх принципах ООП.

## Принципы ООП

- **Абстракция** — общие данные участников учебного процесса вынесены в
  абстрактный класс `Person`; «просто человека» создать нельзя.
- **Наследование** — `Student` и `Teacher` наследуют `Person` и добавляют
  только свои поля, без дублирования кода.
- **Инкапсуляция** — все поля закрыты (`private readonly`), наружу
  выставлены свойства только для чтения; данные проверяются в конструкторах.
- **Полиморфизм** — карточка участника и его роль (`Role`) выводятся через
  базовый класс; список «Все участники» работает с `List<Person>`.

## Правила проверки данных

- пустые имя, кафедра и название курса не принимаются;
- возраст: 16–100, год обучения: 1–6, стаж: 0–70, объём курса: 1–300 ч.;
- номер студенческого билета: 6 цифр, не может повторяться;
- почта обязана содержать «@», точку после него и не содержать пробелов;
- повторная запись студента на курс отклоняется;
- программа не завершается аварийно: закрытый ввод и любые ошибки
  ввода обрабатываются.

## Команды меню

| Команда | Действие |
|---|---|
| 1 | Добавить студента |
| 2 | Информация о студенте и его курсах |
| 3 | Добавить преподавателя |
| 4 | Информация о преподавателе и его курсах |
| 5 | Создать курс |
| 6 | Информация о курсе и список студентов на нём |
| 7 | Записать студента на курс |
| 8 | Назначить преподавателя на курс |
| 9 | Список всех студентов |
| 10 | Список всех преподавателей |
| 11 | Список всех курсов |
| 12 | Все участники учебного процесса (через базовый класс) |
| 0 | Выход |

## Структура проекта

- `Enums/AcademicDegree.cs` — учёные степени преподавателя
- `Models/Person.cs` — абстрактный участник учебного процесса
- `Models/Student.cs` — студент
- `Models/Teacher.cs` — преподаватель
- `Models/Course.cs` — курс со связью на преподавателя и студентов
- `Services/UniversityRepository.cs` — хранилище и операции LINQ
- `Utils/Input.cs` — чтение и проверка данных
- `Program.cs` — меню и вывод

При запуске университет заполняется тестовыми данными: три студента,
два преподавателя и три курса с записями.

## Запуск

```bash
dotnet run
```
