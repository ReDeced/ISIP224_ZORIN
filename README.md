# Практика №6 — Текстовая пошаговая игра-рогалик

Консольная игра на C# (.NET 8). Все случайные события определяются
генератором случайных чисел: встреча сундука/врага, тип врага, крит,
заморозка, величина блока и параметры предметов.

## Ход игры

- Каждый ход с вероятностью 50 на 50 выпадает сундук или враг.
- Каждый десятый ход герой встречает случайного босса.
- Бой: герой ходит первым и выбирает **Атаку** или **Защиту**.
- Защита: 40% шанс полностью уклониться от следующей атаки врага,
  иначе блок уменьшает урон на случайные 70–100% характеристики защиты.
- После действия героя враг атакует, применяя свои особенности.

## Сущности

| Сущность | Особенности |
|---|---|
| Гоблин | шанс критического удара (×2 урона) |
| Скелет | полностью игнорирует защиту героя |
| Маг | шанс наложить заморозку (пропуск хода) |
| ВВГ | босс-гоблин: HP ×2.0, атака ×1.5, защита ×1.2, крит +10% |
| Ковальский | босс-скелет: HP ×2.5, атака ×1.3, защита ×1.4 |
| Архимаг C++ | босс-маг: HP ×1.8, атака ×1.6, защита ×1.1, заморозка +10% |
| Пестов С-- | босс-скелет: HP ×1.3, атака ×1.8, защита ×0.6, заморозка +15% |

## Сундук

Из сундука случайно выпадает лечебное зелье (мгновенно лечит полностью),
оружие или доспех. Перед заменой экипировки показываются характеристики
нового предмета и текущего, предмет можно взять или выбросить.

## Дополнительные задания

- **Редкость предметов**: обычный/редкий/эпический/легендарный, шанс
  выпадения по весам 50/30/15/5, множитель силы 1.0/1.5/2.0/3.0.
- **Сохранение и загрузка**: прогресс (имя, здоровье, экипировка,
  заморозка, номер хода) пишется в `roguelike_save.json` после каждого
  хода; в меню доступно «Продолжить»; при смерти сохранение удаляется.

## Принципы ООП

- **Абстракция** — абстрактные классы `Enemy` и `Item` описывают общее.
- **Наследование** — расы наследуют `Enemy`, боссы наследуют свои расы,
  оружие/доспех/зелье наследуют `Item`.
- **Инкапсуляция** — здоровье и экипировка изменяются только методами,
  конструкторы проверяют корректность характеристик.
- **Полиморфизм** — бой работает с врагом через базовый класс, особенности
  врага включаются виртуальными свойствами (`CritChance`, `IgnoresDefense`,
  `FreezeChance`).

## Структура проекта

- `Enums/Rarity.cs` — редкость предметов
- `Models/Player.cs` — герой и его экипировка
- `Models/Enemy.cs`, `Goblin.cs`, `Skeleton.cs`, `Mage.cs` — враги
- `Models/Vvg.cs`, `Kovalsky.cs`, `ArchmageCpp.cs`, `Pestov.cs` — боссы
- `Models/Item.cs`, `Weapon.cs`, `Armor.cs`, `HealingPotion.cs` — предметы
- `Services/ItemFactory.cs` — генерация предметов с учётом редкости
- `Services/Chest.cs` — сундук и замена экипировки
- `Services/Battle.cs` — боевая система
- `Services/Game.cs` — игровой цикл
- `Services/SaveManager.cs` — сохранение и загрузка в JSON
- `Utils/Input.cs` — безопасный ввод
- `Program.cs` — стартовое меню
