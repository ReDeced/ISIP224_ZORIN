# Практика №7 — Маркетплейс GMWOG || GG.MOW || WONGG

Консольное приложение на C# (.NET 8) с базой данных SQLite
(`MarketplaceDatabase.db`, создаётся при первом запуске и наполняется
тестовыми товарами и ПВЗ).

## База данных (3НФ)

| Таблица | Назначение |
|---|---|
| `User` | пользователи: ник, хеш пароля, дата регистрации |
| `Category` | справочник категорий |
| `Product` | товары: ссылка на категорию, цена, остаток, описание |
| `PickupPoint` | пункты выдачи заказов (ПВЗ) |
| `CartItem` | корзина: ссылки на пользователя и товар, количество |
| `Order` | заказ: пользователь, ПВЗ, дата |
| `OrderItem` | состав заказа: товар, количество, цена на момент покупки |

Правила именования соблюдены: таблицы в единственном числе на английском,
CamelCase без пробелов и подчёркиваний, первичные ключи `Id`, внешние —
`UserId`, `ProductId`, `CategoryId`, `PickupPointId`, `OrderId`.
Сумма заказа не хранится, а вычисляется по позициям `OrderItem`;
категория вынесена в отдельную таблицу — база нормализована до 3НФ.

## Возможности

- **Гость**: просмотр каталога, регистрация, вход.
- **Регистрация**: уникальный ник без пробелов, пароль от 4 символов,
  подтверждение пароля; в базе хранится только SHA256-хеш.
- **Вход** зарегистрированного пользователя по нику и паролю.
- **Корзина**: добавление с учётом остатка склада (одинаковые товары
  объединяются), удаление позиции, очистка.
- **Покупка** отдельного товара или всей корзины: заказ, его позиции
  и списание остатков выполняются в одной транзакции, перед покупкой
  выбирается ПВЗ.
- **История заказов** с сортировкой по дате (сначала новые или старые).

## Команды меню

| Гость | Покупатель |
|---|---|
| 1 — Показать товары | 1 — Показать товары |
| 2 — Регистрация | 2 — Добавить товар в корзину |
| 3 — Вход | 3 — Показать корзину |
| 0 — Выход | 4 — Убрать товар из корзины |
| | 5 — Очистить корзину |
| | 6 — Купить товар из корзины |
| | 7 — Купить всю корзину |
| | 8 — История заказов |
| | 9 — Выйти из аккаунта |
| | 0 — Выход |

## Проверки

Пустые значения, количество больше остатка склада, неверный пароль,
занятый ник, несовпадающее подтверждение, нехватка товара при покупке —
все случаи обрабатываются сообщениями, программа не падает.

## Структура проекта

- `Models/` — `User`, `Category`, `Product`, `PickupPoint`, `CartItem`,
  `Order`, `OrderItem` — модели, повторяющие таблицы базы
- `Services/MarketplaceDatabase.cs` — схема, сидирование, хелперы запросов
- `Services/UserService.cs` — регистрация и вход
- `Services/ProductService.cs` — каталог
- `Services/CartService.cs` — корзина
- `Services/OrderService.cs` — ПВЗ, покупка, история заказов
- `Utils/Input.cs` — безопасный ввод
- `Program.cs` — меню

## Запуск

```bash
dotnet run
```
