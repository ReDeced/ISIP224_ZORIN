# Учёт товаров в магазине

Консольное приложение на C# (.NET 8) для учёта товаров на складе магазина.

## Возможности

- Добавление товара с автоматическим присвоением кода (коды начинаются с 1)
- Удаление товара по коду
- Заказ поставки товара на склад
- Продажа товара с проверкой остатка на складе
- Поиск товаров по коду, названию и категории, а также универсальный поиск
- Вывод всех товаров и списка товаров, которых нет на складе

### Задание со звёздочкой

- История продаж на основе `Stack<Sale>` с возможностью отмены последней продажи
  (товар возвращается на склад)
- Отчёт о продажах: все проданные товары, количество штук и общая сумма

## Команды меню

| Команда | Действие |
|---|---|
| 1 | Добавить товар |
| 2 | Удалить товар |
| 3 | Заказать поставку товара |
| 4 | Продать товар |
| 5 | Поиск товаров |
| 6 | Показать все товары |
| 7 | История продаж |
| 8 | Отменить последнюю продажу |
| 9 | Отчёт о продажах |
| 10 | Товары, которых нет на складе |
| 0 | Выход |

## Проверка ввода

Пустые значения, нечисловой ввод, отрицательные и нулевые цены, отрицательные
количества и коды вне диапазона не принимаются: программа повторяет вопрос,
не завершаясь. Цена вводится через точку или запятую.

## Структура проекта

- `Enums/Category.cs` — категории товаров (4 категории)
- `Models/Product.cs` — товар
- `Models/Sale.cs` — продажа
- `Services/ProductRepository.cs` — хранение и поиск товаров
- `Services/SalesHistory.cs` — история продаж на `Stack`
- `Services/SalesService.cs` — логика продаж и отмены
- `Utils/Input.cs` — чтение и проверка данных с консоли
- `Program.cs` — меню и вывод

При запуске склад заполняется пятью тестовыми товарами.

## Запуск

```bash
dotnet run
```
