Практика №3 — Анализ текста

Консольное приложение на C# (.NET 8), которое принимает текст и выполняет его анализ.
Реализовано без LINQ: используются циклы, массивы, `List<T>` и `Dictionary`.

## Возможности

- Ввод текста от пользователя, минимум 100 символов
- Подсчёт количества слов
- Поиск самого короткого и самого длинного слова
- Подсчёт количества предложений
- Подсчёт гласных и согласных букв (кириллица и латиница, любой регистр)
- Статистика по частоте встречаемости каждой буквы с долей в процентах
- Ввод нового текста и повторный анализ в рамках одной работы программы
- Сохранение статистики по всем текстам в список
- Просмотр сводной таблицы и статистики по отдельному тексту

## Команды меню

| Команда | Действие |
|---|---|
| 1 | Ввести новый текст |
| 2 | Показать статистику по всем текстам |
| 3 | Показать статистику по выбранному тексту |
| 0 | Выход |

## Ввод текста

Текст вводится построчно. Для завершения ввода нужно набрать с новой строки `!done`.
Если текст короче 100 символов, программа попросит продолжить ввод.

## Структура проекта

- `Models/TextStatistics.cs` — хранение и вывод результатов анализа
- `Models/LetterStat.cs` — количество вхождений одной буквы
- `Services/TextAnalyzer.cs` — вся логика анализа
- `Utils/TextInput.cs` — чтение и проверка данных с консоли
- `Program.cs` — меню и работа со списком текстов

## Запуск

```bash
dotnet run
```
