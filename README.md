# Практика №4 — Учёт книг в библиотеке

Консольное приложение на C# (.NET 8). Фильтрация, сортировка и группировка
выполняются через LINQ.

## Параметры книги

Уникальный идентификатор (назначается автоматически), название, автор, жанр,
год издания, цена.

## Команды меню

| Команда | Действие |
|---|---|
| 1 | Добавить книгу |
| 2 | Удалить книгу по идентификатору |
| 3 | Найти книги: по названию, по автору, по жанру |
| 4 | Отсортировать книги: по названию, по году издания |
| 5 | Самая дорогая и самая дешёвая книга |
| 6 | Книги по авторам |
| 7 | Показать все книги |
| 8 | Вставить блок книг |
| 9 | Добавить книгу в корзину |
| 10 | Показать корзину |
| 11 | Убрать книгу из корзины |
| 12 | Очистить корзину |
| 0 | Выход |

## Пакетный импорт

Ввод блока книг в формате `Название;Автор;Жанр;Год;Цена`.
Каждая строка с новой строки, завершение ввода — строка `!done`.
Некорректные строки не останавливают импорт: проблемы выводятся списоком
с номерами строк.

## Корзина

Добавление книги с указанием количества, просмотр состава и итоговой стоимости,
уменьшение позиции и очистка. Повторное добавление той же книги увеличивает
количество в существующей позиции.

## Проверка ввода

Пустые название и автор, неположительная цена и год вне диапазона 1450–текущий
год не принимаются. Цена вводится через точку или запятую. Жанр выбирается
по номеру или по названию. Программа не завершается аварийно при закрытом вводе.

## Структура проекта

- `Enums/Genre.cs` — жанры книг
- `Models/Book.cs` — книга
- `Models/CartItem.cs` — позиция корзины
- `Services/LibraryRepository.cs` — хранение, поиск, сортировка, группировка
- `Services/BatchImporter.cs` — пакетный импорт
- `Services/ShoppingCart.cs` — корзина
- `Utils/Input.cs` — чтение и проверка данных
- `Program.cs` — меню и вывод

При запуске фонд заполняется пятью тестовыми книгами.

## Запуск

```bash
dotnet run
```
